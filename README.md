# 脑洞军团大乱斗

一款自动对战（auto-battler）休闲游戏 DEMO，开罗（Kairosoft）像素画风，目标产出可分发 EXE。

> **Fun Hypothesis**：看着自己的军团沿文明史一路进化、在 5 回合里碾压对手，是这游戏好玩的核心。

## 核心玩法

- **5 回合自动战斗**：双方各起始 3 个单位，随回合扩张，峰值可达 30 个单位。
- **兵种三分类**：近战 / 远程 / 骑兵，构成剪刀石头布克制链，克制方 +20% 伤害。

  | 克制关系 | 说明 |
  |---|---|---|
  | 近战 → 骑兵 | 近战克制骑兵 |
  | 骑兵 → 远程 | 骑兵克制远程 |
  | 远程 → 近战 | 远程克制近战 |

- **文明史升级树**：每个单位沿 `洞穴人 → 青铜剑士 → 重步兵 → 功夫学徒 → 机甲` 进化，属性按指数曲线增长。
- **技能系统**：单位以概率释放强力技能（频率为原始设定的 2/3），技能名由单位自身喊出，不使用屏幕中央横幅。
- **评分规则**：按 5 回合累计击败数（敌人击败总数）计分。

## 美术与表现

- 风格：Kairosoft 开罗像素画风。
- 角色动画：移动、攻击、被攻击、死亡。
