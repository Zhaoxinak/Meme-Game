# 脑洞军团大乱斗

开罗（Kairosoft）像素画风的自动对战（auto-battler）休闲游戏。单文件 HTML，可直接双击打开、分发、或打包 EXE。

> **Fun Hypothesis**：看着自己的军团沿文明史一路进化、在自动团战里碾压对手，是这游戏好玩的核心。守城模式把它延伸成「钱怎么花决定你能守到第几波」的运营抉择。

## 两个模式

| | 守城远征（主模式） | 竞技场（快速局） |
|---|---|---|
| 时长 | 25-35 分钟 | 6-8 分钟 |
| 玩法 | 守住三段城墙挡 20 波敌军；赚金币 → 买兵 / 升科技 / 修城墙 / 建经济 | 5 轮对称团战；每轮抽战术卡、升级一条线 |
| 核心决策 | 经营：钱往哪花（兵 / 科技 / 城墙 / 经济四选） | 进化：Lv3 时二选一走分支（大盾步兵 / 狙击手 / 枪骑兵） |
| 克制链 | 近战→骑兵→远程→近战（+35%） | 同左；分支反转 ×2.6 / 专精 ×2.4 |

## 玩法要点

- **自动战斗**：双方同时出兵全自动开打，但你不是纯看戏——点战术指挥放技能（落雷 / 治疗波）、点应援给全军加 Buff、切 1×/2×/3× 速度、进全屏。
- **守城实时经营**：买兵 / 科技 / 修墙 / 经济四类经营常驻屏幕底部，没有「打开商店」这一步，战斗中、喘息期随时可点，只要钱够。
- **文明史升级**：单位沿 `洞穴人 → 青铜剑士 → 重步兵 → 功夫学徒 → 机甲` 进化，属性指数增长，Lv3 起分岔出三系分支。
- **概率大招**：出手时概率怒吼放大招（飞砖 / 激光 / 长枪 / 醉拳…），一击翻盘。

## 开发

源码是模块化的，`src/` 下按职责分层，构建时拼回单文件：

```bash
node build.js          # 拼装 src/ → 脑洞军团大乱斗.html
node tests/ui_test.js  # 跑测试
```
